# GSB – Gestion des frais (PHP MVC CodeIgniter 4)

Projet BTS SIO SLAM – Situation 5 – Groupe 4 – Mattéo Martins

Application web permettant aux visiteurs médicaux du laboratoire GSB de saisir et consulter leurs fiches de frais (frais forfaitisés et hors forfait).

## Historique
- **v1 (1ère année)** : application en PHP procédural (version actuelle du dépôt).
- **v2 (2ème année, en cours)** : migration vers une architecture MVC avec le framework CodeIgniter 4.

## Contenu
- `*.php`, `*.css`, `*.js` : pages de l'application v1
- `SQL/` : scripts de la base `gsbV2` (création des tables, jeu d'essai, comptes et droits)

## Technologies
PHP 8.2 · MariaDB/MySQL · Apache (LAMP Debian) · HTML/CSS/JS · CodeIgniter 4
